Data Deletion

Iris · How to have your data removed

Iris only connects accounts owned by the Operator and stores the data described in the Privacy Policy. To have data deleted:

1. Disconnect the account

In the Threads app: Settings → Account → Website permissions → Iris → Remove. In the Instagram app: Settings → Website permissions / Apps and websites → Iris → Remove. This invalidates Iris's access token immediately.

2. Request deletion of stored data

Email pcime123@gmail.com with the subject "Iris data deletion" and the account username. All stored tokens, queue items, logs and search candidates relating to that account are deleted within 7 days, and a confirmation is sent by email.

Public posts seen through keyword search

If your public post appeared in Iris's search candidates and you want it removed from Iris's records, email the same address with the post link. Candidates are in any case deleted automatically after 30 days.
